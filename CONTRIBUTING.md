# Contributing

Thanks for helping! Bug reports, ideas and pull requests are welcome, in English or Portuguese.

- Setup, build and debugging: [docs/en/development.md](docs/en/development.md)
  ([Português](docs/pt-BR/desenvolvimento.md)).
- Keep the app dependency-free and compatible with webOS 5+ (Chromium 68).
- Everything must work with the D-pad and with the Magic Remote pointer.
- Never commit API keys, TV keys, IPTV credentials or IP addresses.
- Keep pull requests focused, say how you tested them (browser, TV model, webOS version) and add
  screenshots for visual changes.
- Use [Conventional Commits](https://www.conventionalcommits.org/) and update `CHANGELOG.md` under "Unreleased".

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
